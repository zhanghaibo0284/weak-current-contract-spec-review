### 11.1 问题清单主模板（7 字段，强制）

每一条问题必须且至少包含以下 7 个字段；字段名稳定，便于跨工具汇总。

| 字段 | 名称 | 说明 | 填写规范 |
|---|---|---|---|
| f1 | 问题编号 | 全局唯一编号，格式 `审查批次-序号`，如 `CSR-001`；`判定依据` 中须带规则集前缀（`RISK-` / `QTY-` / `PARAM-`） | 不可重复；增量复核沿用原编号 |
| f2 | 对应条款或材料位置 | 文件名 + 册/章节/条款号/页码/表格行列；如「第一册 1.2 工程范围 / 设备材料表 第6章」 | 必须可定位到原文；优先章节号，页码为辅 |
| f3 | 问题描述 | 客观描述命中内容：原文摘录 + 异常表现，不作主观定性 | 引用原文，不改写含义 |
| f4 | 判定依据 | 命中的检查项编号与判定信号、所用规则、核算过程（如理论量 vs 清单量、偏差率） | 必须带规则集前缀；量化优先 |
| f5 | 风险等级 | 高 / 中（待核验）/ 低；问题条目**不得**填「不适用」 | 与 `rules/severity.md` 7.3 升级规则一致 |
| f6 | 影响分析 | 可能的后果：成本敞口、工期、验收、回款、合规与责任影响；尽量量化最不利值 | 需量化时套用 `templates/cost-model.md` 公式 |
| f7 | 整改建议 | 具体可执行动作：澄清问题、成本预留、条款修订、审批启动、责任人与时限 | 动词开头，可验收 |

#### 清单表头（直接复制）

> 台账与清单表头须附 `rules/limitations.md` 的 7 条边界声明（`{{BOUNDARY_NOTICE}}`）。

```markdown
| f1 问题编号 | f2 对应条款或材料位置 | f3 问题描述 | f4 判定依据 | f5 风险等级 | f6 影响分析 | f7 整改建议 |
|---|---|---|---|---|---|---|
```

#### 单条问题输出示例（已填）

| 字段 | 内容 |
|---|---|
| f1 问题编号 | CSR-003 |
| f2 对应条款或材料位置 | 《技术规格书》第一册 3.2.4 / 设备材料表「PLC 冗余配置」行 |
| f3 问题描述 | 原文：「PLC 采用单机配置，重要站点可采用冗余配置。」设备材料表按 1 套/站列项；而可靠性要求章节载明「任一单点故障不得导致全线降级」。 |
| f4 判定依据 | 命中 `QTY-R01`（冗余 PLC 配置）与 `RISK-A04`（开口工程量）；冗余站点应配 2 套，10 站理论量 20 套 vs 清单 10 套，偏差 50%（> 5% 阈值）。 |
| f5 风险等级 | 高（命中「开口工程量 + 遗漏免费补齐」升级条件） |
| f6 影响分析 | 若按单机交付则不满足可靠性条款，验收存在不通过风险；若后续补配，按报价册单价估算约 ¥XX 万，且总价不变条款下由我方承担。 |
| f7 整改建议 | 在澄清阶段书面确认冗余范围与套数；要求业主明确「重要站点」定义并把套数写入设备材料表；同步修订合同总价或写入除外条款。责任人：技术负责人 + 商务经理；时限：交底会后 5 个工作日。 |

#### 可选扩展字段（缺失不构成错误）

| 字段 | 名称 | 取值 | 用途 |
|---|---|---|---|
| x1 | 状态 | 待澄清 / 已澄清 / 已关闭 / 放弃 | 闭环状态机，见 `rules/workflow.md` 10.6 |
| x2 | 置信度 | 确认 / 疑似 / 线索 | 人工剔除排序：确认 > 疑似 > 线索 |
| x3 | 命中方式 | 关键词 / 表格核算 / 交叉推断 / 外部证据 | 便于复现 |
| x4 | 规则版本 | 如 `1.0.0+sha256:ab12…` | 审计留痕 |
| x5 | 实际责任人 | 实名/岗位 | 落地跟踪 |
| x6 | 关闭时间 | `YYYY-MM-DD` | 状态为已关闭/放弃时必填 |
| x7 | 证据文件 | 原件文件名/版本/页码 | 审计取证 |

#### 常见填写错误与提示语

| 错误写法 | 问题 | 应改为 |
|---|---|---|
| 风险等级写「中高」 | 枚举外取值，汇总失败 | 「中（待核验）」并在影响分析中标注 M1/M2 子级别 |
| 问题条目风险等级写「不适用」 | 语义错位 | 该规则不进问题清单，只在覆盖台账写结论=不适用 |
| 判定依据只写「R05」 | 同号歧义 | `QTY-R05` 或 `RISK-R05`，按实际规则集 |
| 位置只写「第 12 页」 | 页码为估算值 | 写「第二册 4.1.3 条 / 表 4-2 第 3 行」 |
| 影响分析写「存在风险」 | 不可决策 | 给出金额区间、工期天数或验收后果，缺失输入时标「待核验」 |
