# 澄清问题单（RFI）与版本差异登记表

> 文件：`templates/rfi-list.md`
> 职责：把「待核验」转化为可发给业主/设计院的书面问题；并登记版本变更对规则的影响。
> 与问题清单的区别：问题清单记「我方识别的风险」，RFI 记「需要对方回答/提供的事项」。
> 关联：`rules/workflow.md` 10.6、`rules/inputs.md` 5.4、`rules/parsing.md` 第 3 节。

---

## 1. 材料缺口清单（材料不齐时先出这张）

```markdown
| # | 缺失材料 | 影响规则集 / 规则数 | 影响的结论 | 需提供方 | 期望日期 | 替代证据 |
|---|---|---|---|---|---|---|
| 1 | 设备材料表（BOQ） | QTY 16 条 + RISK-D/部分 | QTY 全部待核验 | 业主/设计院 | YYYY-MM-DD | 报价册清单 |
```

> 缺料影响必须量化到「影响多少条规则、哪些结论会变成待核验」，否则无法据此决定是否启动全量审查。

## 2. 澄清问题单（RFI）

| 字段 | 名称 | 说明 |
|---|---|---|
| r1 | 问题编号 | `RFI-001`，与问题清单编号体系独立 |
| r2 | 问题来源 | 关联的规则编号（带前缀）或问题编号 |
| r3 | 问题描述 | 一句话问句，不含我方结论 |
| r4 | 依据条款/位置 | 锚点格式，见 `rules/parsing.md` 第 2 节 |
| r5 | 需对方提供/确认 | 具体材料、数值、适用范围或书面答复 |
| r6 | 答复方 | 业主 / 设计院 / 集成商 / 厂家 |
| r7 | 期望答复日期 | 与项目节点绑定（如交底会后 5 个工作日） |
| r8 | 我方影响 | 若答复延迟或不利，对成本/工期/验收的影响 |
| r9 | 状态 | 待发 / 已发 / 已答复 / 已关闭 / 升级 |
| r10 | 答复摘要与结论 | 答复要点 + 是否消除风险 |

```markdown
| r1 | r2 来源 | r3 问题 | r4 依据 | r5 需确认 | r6 答复方 | r7 期限 | r8 我方影响 | r9 状态 | r10 答复摘要 |
|---|---|---|---|---|---|---|---|---|---|
| RFI-001 | QTY-R01 | 「重要站点」的具体范围是否包含全部 10 座车站？冗余 PLC 是否每站 2 套？ | SPEC-01#第1册/3/3.2/3.2.4 | 冗余范围与套数的书面确认 | 设计院 | 2026-11-26 | 若仅 5 站冗余，成本敞口约 ¥XX 万 | 待发 | |
```

**填写要求**

1. r3 必须是问句，不得夹带定性判断（判断留在问题清单）。
2. 一问一条，不合并多个诉求；合并会导致答复不完整。
3. r8 必须给影响；无法量化时写「影响范围：验收/工期/成本」并标「待量化」。
4. 已答复的条目须回填 r10，并同步更新覆盖台账结论与问题状态。

## 3. 版本差异登记表（增量复核用）

```markdown
### 规格书 v1 → v2 差异

| # | 变更位置 | 变更类型 | 变更摘要 | 受影响规则（带前缀） | 受影响问题编号 | 结论变化 |
|---|---|---|---|---|---|---|
| 1 | SPEC-01#第2册/5/5.3 | 参数修改 | 摄像头分辨率 1080P→4K | PARAM-P40, PARAM-P41 | CSR-007 | 待核验→存在风险 |
| 2 | CON-01#正文/8/8.2 | 条款新增 | 新增 3 年原价供货 | RISK-D04, PARAM-P58 | 新增 CSR-012 | 新增 |
```

**增量复核规则**（配合 `rules/workflow.md` 10.6）

1. 只重跑「受影响规则」，未受影响行保持原结论与原问题编号。
2. 变更导致原结论失效时，把原行结论改为「待核验」并注明「v2 变更，复核中」，**不得直接删除**。
3. 新增事实新增问题编号；被替代的条目在 `备注` 写「替代 CSR-00X」。
4. 差异表须与覆盖台账同一批次号和规则校验和。

## 4. 交付节奏建议

| 节点 | 交付物 | 目的 |
|---|---|---|
| 材料收齐前 | 材料缺口清单 | 决定能否启动全量审查 |
| 交底会前 | RFI（高风险相关优先） | 会上直接对焦 |
| 交底会后 | 问题清单 + 覆盖台账 + 报告 | 形成书面结论 |
| 补遗/改版后 | 版本差异登记表 + 增量复核台账 | 只重跑受影响项 |
