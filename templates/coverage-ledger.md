# 全量覆盖台账（G1 强制交付物）

> 文件：`templates/coverage-ledger.md`
> 职责：记录 **187 条**检查项（`RISK-` 108 + `QTY-` 16 + `PARAM-` 63）的逐项结论，用于兑现 G1「风险无遗漏」。
> 地位：与问题清单并列的强制产物；**只出问题清单、不出覆盖台账，视为审查未完成**。
> 机器契约：`templates/coverage-schema.json`。
> 边界：台账是「审查过程记录」，不是「问题清单」；结论=符合/不适用 的行不进入问题清单。

---

## 1. 生成规则

1. 每条规则**必须且仅出现一次**，行数恒等于 187（quick 档按所选子集，须在表头注明 `档位=quick，应出 N 行`）。
2. `结论` 只能取：`符合` / `存在风险` / `待核验` / `不适用`。
3. `存在风险` 的行必须填 `问题编号`（回填问题清单 f1）；`待核验` 的行必须填 `需补充材料或异常码`；`不适用` 的行必须填 `不适用理由`。
4. 不得用「无」「—」「空」代替结论；不得合并同类项。
5. 增量复核时保留全部行，只更新结论与 `复核时间`，并保持 `问题编号` 稳定。

---

## 2. 表头

```markdown
| 规则编号 | 规则集 | 检查项名称 | 结论 | 证据位置（锚点） | 问题编号 | 需补充材料 / 异常码 | 置信度 | 备注 |
|---|---|---|---|---|---|---|---|---|
```

- `规则编号`：完整形式，如 `PARAM-P56`（消歧见 `rules/indexes.md` A.4）。
- `证据位置`：遵循 `rules/parsing.md` 第 2 节锚点规范；无材料时填「材料缺失」。
- `置信度`：确认 / 疑似 / 线索，仅对 `存在风险` 与 `待核验` 有意义。

## 4. 完整性自检（输出前必做）

| 检查 | 通过标准 |
|---|---|
| 行数 | `standard` 档 = 187；`quick` 档 = 表头声明值 |
| 编号唯一 | 无重复、无遗漏（按规则集逐个比对） |
| 结论合法 | 仅四类取值，无空值 |
| 关联一致 | 每个 `存在风险` 都能在问题清单找到 `问题编号` |
| 待核验可行动 | 每个 `待核验` 都有具体材料或异常码 |
| 版本留痕 | 表头含 `规则版本` 与 `{{RULESET_CHECKSUM}}` |

> 可用 `python verify_skill.py --ledger <台账文件>` 机器校验上述前 4 项。
