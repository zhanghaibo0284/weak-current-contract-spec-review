## 6. 审查维度体系

审查维度为**可配置分类层**：7 个核心维度（覆盖用户指定的审查要点）+ 5 个扩展维度（覆盖其余合同风险），  
合计 12 个维度完整映射源数据的 20 个风险类别。维度编号与名称可在配置中调整。

### 6.1 核心维度（7 个）

| 维度编号   | 维度名称    | 覆盖原类别 | 审查焦点                                          |
| ------ | ------- | ----- | --------------------------------------------- |
| DIM-01 | 技术参数一致性 | C     | 核对技术参数是否满足规格书/标准/招标要求，且口径可验证、与投标响应及厂家资料三方一致。  |
| DIM-02 | 品牌型号符合性 | O,C   | 核对品牌型号是否被锁定、供货可得性、替代认定规则与背靠背传导，防止换型违约与长期原价供货。 |
| DIM-03 | 接口协议兼容性 | E     | 核对接口对象、协议版本、点表、对端配合方与兼容性书面确认，避免联调阶段集中暴露。      |
| DIM-04 | 数量清单核对  | D     | 核对设备材料表与功能、架构、点数闭合，清单内部一致，配套件与免费义务全部开项。       |
| DIM-05 | 施工边界划分  | B,S   | 核对界面划分表是否落到设备/接口级，第三方、现场条件与施工配合责任是否明确。        |
| DIM-06 | 验收标准    | K,G   | 核对验收链判据、测试工况、检测责任与引用标准现行有效性，确保可验证、可闭环。        |
| DIM-07 | 质保与售后责任 | L     | 核对质保起算点、备件长期供货、响应时限、RAMS 口径与周期性服务的全周期成本。      |

### 6.2 扩展维度（5 个）

| 维度编号   | 维度名称      | 覆盖原类别 | 审查焦点                                  |
| ------ | --------- | ----- | ------------------------------------- |
| DIM-08 | 合同效力与商务口径 | A,H,Q | 核对文件组成与优先级、固定总价与开口条款冲突、付款结算与取费口径。     |
| DIM-09 | 变更与履约控制   | I,J   | 核对书面变更流程、需求蔓延、免费义务、工期节点与顺延机制。         |
| DIM-10 | 知识产权与交付物  | F,M,N | 核对软件许可与源码 IP、图纸文档 BIM、培训组织等交付义务的可履行性。 |
| DIM-11 | 责任划分与风险兜底 | P,T   | 核对罚则上限、责任上限、保险、单方裁量与开放式兜底措辞。          |
| DIM-12 | 移交与项目收尾   | R     | 核对三权/资产/资料移交、台账录入、切分结算与遗留问题闭环。        |

### 6.3 类别—维度—证据来源映射

| 原类别 | 类别名称           | 主维度              | 主要证据来源                                          |
| --- | -------------- | ---------------- | ----------------------------------------------- |
| A   | 合同文件构成与效力      | DIM-08 合同效力与商务口径 | 合同正文「文件组成/附件清单」条款、各合同附件（规格书各册、报价册、图纸、澄清补遗、谈判纪要） |
| B   | 工程范围、界面与责任划分   | DIM-05 施工边界划分    | 合同/技术规格书「工程范围/界面划分表」、第三方与关联单位分工条款、现场勘查记录        |
| C   | 技术参数与性能指标      | DIM-01 技术参数一致性   | 技术规格书「技术参数/性能指标」章节、投标技术响应表、产品彩页与检测报告            |
| D   | 设备清单、数量与工程量    | DIM-04 数量清单核对    | 设备材料表、报价册、功能需求与系统架构章节、点数统计表                     |
| E   | 接口、集成与外部依赖     | DIM-03 接口协议兼容性   | 技术规格书「接口/通信/接口试验」章节、接口点表、对端厂家书面资料               |
| F   | 软件、许可、源代码与知识产权 | DIM-10 知识产权与交付物  | 技术规格书「软件架构/软件交付」章节、软件与 License 清单、许可协议          |
| G   | 标准规范与合规认证      | DIM-06 验收标准      | 技术规格书「标准规范/信息安全」章节、认证证书与检测报告清单、等保测评要求           |
| H   | 商务报价与价格口径      | DIM-08 合同效力与商务口径 | 合同商务册（价格/分包条款）、报价册、采购定价文件                       |
| I   | 变更、需求蔓延与免费义务   | DIM-09 变更与履约控制   | 合同「变更/买方权利」条款、谈判纪要、设计联络会纪要                      |
| J   | 工期、里程碑与分段开通    | DIM-09 变更与履约控制   | 合同「工期/里程碑」条款、工程计划与开通节点安排                        |
| K   | 测试、检验与验收       | DIM-06 验收标准      | 技术规格书「测试/检验/调试/验收」章节、验收规范、检测条款                  |
| L   | 质量、质保与售后服务     | DIM-07 质保与售后责任   | 合同/技术规格书「质量/质保/售后服务/RAMS」章节                     |
| M   | 图纸、文档、BIM 与交付物 | DIM-10 知识产权与交付物  | 技术规格书「图纸/文档/BIM」章节、交付物清单                        |
| N   | 培训、组织与人员       | DIM-10 知识产权与交付物  | 技术规格书「培训」章节、项目组织机构与人员配置要求                       |
| O   | 分包、供方与品牌型号     | DIM-02 品牌型号符合性   | 合同商务册「采购/分包」条款、采购合同、供方资质与认定材料                   |
| P   | 违约、罚则、责任上限与保险  | DIM-11 责任划分与风险兜底 | 合同商务册「违约/罚则/责任/保险」条款                            |
| Q   | 付款、结算与成本预留     | DIM-08 合同效力与商务口径 | 合同商务册「付款/结算」条款、报价册、取费口径文件                       |
| R   | 移交、资产与项目收尾     | DIM-12 移交与项目收尾   | 技术规格书「移交」章节、资产台账与 EAM/ERP 要求                    |
| S   | 现场条件、外部环境与不可抗力 | DIM-05 施工边界划分    | 技术规格书「现场条件/环境」章节、现场勘查与前置条件确认记录                  |
| T   | 兜底条款与措辞陷阱      | DIM-11 责任划分与风险兜底 | 合同全文与技术规格书全文（★条款、开放式措辞、单方裁量表述）                  |
