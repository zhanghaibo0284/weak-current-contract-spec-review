# 术语表

> 文件：`rules/glossary.md`
> 职责：统一弱电 / 智能化 / 轨道交通机电集成常用术语，减少跨团队与跨执行主体的理解偏差。
> 使用原则：本表只解释含义，不改变任何检查项的判定口径；术语与规格书冲突时以规格书定义为准。

---

## 1. 系统与架构

| 术语 | 含义 | 常见审查关注点 |
|---|---|---|
| ISCS | 综合监控系统，集成/互联多个机电子系统 | 集成深度、接口协议、互联 vs 集成责任边界 |
| BAS | 建筑设备监控系统（楼宇自控） | 监控点表、DDC 数量、协议（BACnet/Modbus） |
| FAS | 火灾自动报警系统 | 与 BAS/ISCS 的联动、消防验收 |
| PSCADA | 电力监控系统 | 遥测遥信遥控、与供电专业接口 |
| SCADA | 数据采集与监视控制 | 实时性、冗余、历史数据 |
| PLC | 可编程逻辑控制器 | 冗余、点数余量、I/O 模块 |
| RTU | 远程终端单元 | 通信规约、环境适应性 |
| IBP | 综合后备盘（车站控制室） | 与 FAS/BAS 的硬线联动 |
| FEP | 前置处理机 / 通信前置 | 协议转换、并发、单点故障 |
| 车控室 | 车站控制室 | 操作台、IBP、值班终端配置 |

## 2. 可靠性与冗余

| 术语 | 含义 | 常见审查关注点 |
|---|---|---|
| 2N | 双套独立配置，任一套可承担全部负载 | 是否真双路、是否共享单点（如共享交换机） |
| N+1 | N 套工作 + 1 套备用 | 备用是否自动投入 |
| 双机热备 | 两台主机互为备份，故障自动切换 | 切换时间、共享存储、脑裂 |
| 冗余 | 关键部件/链路重复配置 | 冗余范围（全线/重要站）是否明确 |
| 单点故障 | 任一部件失效导致系统降级 | 与「任一单点故障不得导致全线降级」条款对应 |
| 后备时间 | UPS/电池维持供电的时长 | 分区核算，常与负载功率联动 |
| 可用性 | 系统可正常工作的时间比例 | 是否给出量化指标与考核方式 |

## 3. 数量与计量

| 术语 | 含义 | 常见审查关注点 |
|---|---|---|
| 点数 | I/O 点位数（AI/AO/DI/DO） | 余量、是否含备用点、统计口径 |
| 甩站 | 本站暂不实施、预留后续接入 | 是否计入本期数量、接口是否预留 |
| 装机量 | 实际部署的设备数量 | 与许可数、备件比例联动 |
| 备件比例 | 备件占设备总量的百分比 | 计算基数（合同设备总价 or 数量） |
| 甲供 / 乙供 | 甲方供应 / 乙方供应 | 供货边界、责任划分、进场检验 |
| 暂列金 | 合同预留、按实结算的金额 | 是否被要求免费消化 |

## 4. 网络与安全

| 术语 | 含义 | 常见审查关注点 |
|---|---|---|
| 等保 | 网络安全等级保护（常指三级） | 定级备案、测评、整改闭环 |
| 汇聚 / 接入交换机 | 网络分层设备 | 端口数、PoE 预算、光模块配套 |
| PoE | 以太网供电 | 功率预算、受电设备数量 |
| ONVIF | 安防设备互操作标准 | 协议版本、是否被私有协议绑定 |
| 视频存储 | 录像保存 | 存储天数、码率、磁盘冗余（RAID） |
| 周界 | 园区/车站外围防区 | 探测手段、误报率、联动 |

## 5. 机房与配套

| 术语 | 含义 | 常见审查关注点 |
|---|---|---|
| UPS | 不间断电源 | 容量、后备时间、并机冗余 |
| 精密空调 | 机房专用恒温恒湿空调 | 制冷量、冗余（N+1）、送风方式 |
| 列头柜 | 机房列级配电柜 | 回路数、监测、双路引入 |
| 动环监控 | 机房动力环境监控 | 监测点、告警联动 |
| KVM | 多机切换管理 | 端口数、远程访问 |
| 综合布线 | 结构化布线系统 | 链路长度、测试参数、配线架数量 |

## 6. 合同与流程

| 术语 | 含义 | 常见审查关注点 |
|---|---|---|
| 开口条款 | 数量/范围可变动、总价不变的条款 | 「据实结算」「总价不变」组合风险 |
| 兜底条款 | 「包括但不限于」「最低要求」「负总责」 | 是否把未列明义务全部转移给我方 |
| 背靠背 | 上游合同义务传导至下游采购合同 | 采购合同是否同步罚则与免费义务 |
| 罚则上限 | 违约金累计封顶 | 上限比例、是否可突破 |
| 履约保函 | 保证履约的银行保函 | 比例、有效期、释放条件 |
| 预付款保函 | 对应预付款的担保 | 是否要求、何时释放 |
| 转包 / 违法分包 | 将全部或主体工作转给他人 | 合法性、资质、责任 |
| 厂验（FAT） | 工厂验收测试 | 测试项、见证方式、遗留项 |
| 现场验收（SAT） | 现场安装后的验收 | 与 FAT 的衔接、复测范围 |
| 完工测试 | 单系统功能测试 | 判据、记录 |
| 144 小时连续试验 | 系统连续稳定运行考核 | 中断判定、重新计时规则 |
| 预验收 / 竣工验收 | 阶段性与最终验收 | 前置条件、资料清单 |
| 质保期 | 缺陷责任期 | 起算点、响应时限、备件供应 |
| 隐蔽工程 | 覆盖后不可见的部分 | 隐蔽验收记录、影像资料 |
