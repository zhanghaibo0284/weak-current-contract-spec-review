## 7. 风险分级标准

采用三级基准 + 两类升级规则；等级词表与阈值可配置。

### 7.1 等级定义与处置要求

| 等级 | 标识           | 判定标准                                       | 处置要求                                            |
| -- | ------------ | ------------------------------------------ | ----------------------------------------------- |
| 高  | 🔴 高风险       | 可能导致实质性不响应、无限/开口责任、验收或回款受阻、重大罚则或无补偿的成本超支。  | 须在合同谈判或澄清阶段形成书面结论；未闭环不得进入详细设计与批量采购，并列入项目一级风险台账。 |
| 中  | 🟡 中风险 / 待核验 | 可能引发成本增加、工期压力、责任争议或额外资源投入；或材料/信息不足，当前无法判断。 | 须形成书面澄清或在内部作成本、工期预留并登记台账，指定责任人与闭环时限。            |
| 低  | 🟢 建议优化      | 格式、表述、管理性瑕疵，影响可控，不构成实质性不响应。                | 纳入常规复核与文档优化，可在项目例会中批量处理。                        |

### 7.2 待核验语义

当出现以下任一情形，判为「中 / 待核验」，不得判为「符合」或「不存在」：

- 材料缺失、条款后果不明、需外部（厂家/业主/第三方）确认；
- 关键参数未取得书面确认、检测报告或实测记录；
- 参数核实类问题命中时统一输出「待核验」线索，只给核对清单，不作定性结论。

### 7.3 升级规则

升级动作只允许落到 `高` / `中（待核验）` / `低` 三个已定义等级，**不得产生「中高」「中低」等未定义等级**。
需要表达强弱差异时，用「在 `中（待核验）` 下标注子级别 M1/M2」，或在 `影响分析` 中量化，不新增等级。

| 触发条件                               | 升级动作（仅限已定义等级） |
| ---------------------------------- | --------------- |
| 数量/比例偏差 > 5%，且涉及「遗漏免费补齐、总价不变」等开口条款 | 升级为 `高`         |
| 参数不足导致功能无法实现或验收不通过                 | 升级为 `高`         |
| 兼容性冲突触发「不得改变型号品牌」或影响工期/等保          | 升级为 `高`         |
| 指标为 ★ 条款，或无测试工况/测量方法/验收判据          | 升级为 `高`         |
| 证据缺失涉及强制认证或进场条件                    | 升级为 `高`         |
| 联动漏项被兜底条款覆盖，累计金额大                  | 至少 `中（待核验）`；累计金额大或影响验收时升级为 `高` |
| 形式校验中发现实质价差或实质矛盾                   | 至少 `低`；构成实质性不响应或影响结算时升级为 `中（待核验）` 或 `高` |

### 7.4 判定结论与风险等级的关系（消歧）

`判定结论` 与 `风险等级` 是两套独立枚举，只是共享「不适用」一词，语义不同：

| 场景 | 判定结论（覆盖台账用） | 风险等级（问题条目用） |
|---|---|---|
| 条款已覆盖、可接受 | 符合 | 不输出问题条目 |
| 命中异常判定信号 | 存在风险 | `高` / `中（待核验）` / `低` 之一 |
| 材料缺失或无法判断 | 待核验 | 固定为 `中（待核验）` |
| 本项目不涉及该条款 | 不适用 | **不得**填「不适用」，该规则不进问题清单，只进覆盖台账 |

> 约束：问题条目的 `风险等级` 出现「不适用」一律视为输出错误；「不适用」仅允许出现在覆盖台账的 `结论` 列。
