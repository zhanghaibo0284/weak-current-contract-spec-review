### 8.2 数量配比核查项（16 条）

> 使用：先确定驱动因子与计量口径，按「理论量 = 驱动因子 × 系数」核算，与清单量比对；偏差 >5% 或比例明显异常即登记待核验。所有配比均为**经验基线而非标准**。

| 编号 | 设备/项 | 驱动因子 | 经验配比基线 | 核算方法 | 异常信号与示例 | 证据来源 | 结论/理论量/偏差 |
|---|---|---|---|---|---|---|---|
| R01 | 冗余 PLC 控制器（车站 A/B 端） | 车站数 N、冗余层级 R | 每站 A、B 两端各 1 套 → 2N；若每端再按双机热备冗余配置 → 4N。即通常为车站数量的 2 倍或 4 倍。 | 理论量 = N × 2 × R（R=1 或 2），车辆段/中心另计。先确认「套」是指一套 CPU 机架还是含 I/O 从站，再核算。 | N=10 → 理论 20 或 40 套。清单给 12 套（少配/冗余层级理解错）、24 套（口径不一）、45 套（重复计列）均属比例异常，须重点核查。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R02 | 车站级工作站 / 操作终端 | 车站数 N × 每站配置 K | N×K；中心级、车辆段、培训/仿真系统另计，不并入车站数。 | 理论量 = N×K + 中心 + 车辆段 + 培训系统。逐站核对配置表，避免把中心设备摊入车站数。 | N=10、每站 4 台 → 40 台 + 中心若干；清单恰为 40 台而中心未开项，说明中心工作站漏配。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R03 | I/O 模块与监控点数 | 监控点数 P、单模块通道数 C（8/16/32） | 模块数 = ceil(P/C) × (1+10%~20% 余量)；AI/AO/DI/DO 分类型各自计算。 | 按「监控对象—点类型—单站点数—站数」重算总点数，再按模块通道数向上取整，与清单逐类比对。 | 按每站 124 点经验值估 2600 点，详设后每站达 140 点且新增机电消防管网传感器 → 实际 2800+ 点，AI 模块明显不足。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R04 | 各类传感器 | 每站分类数量 × 车站数 N | 按类型（温湿度、CO₂、风管型、压力、液位等）逐项重算后求和，不可用「每站均值」一次性估算。 | 逐类型列「单站数量×N」，再与清单数量比对；新增功能（如智慧厕所）单独追加。 | 同类项目每站风管型温湿度传感器至少 12 只 → 10 站应为 120 只；清单按每站 10 只估且总量 210 只，自相矛盾，预估全线超投标量约 40 只。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R05 | 接入 / 汇聚交换机 | 车站数 N × 每站台数，双网冗余 ×2 | 车站接入交换机 = N×每站台数×（双网 2）+ 中心 + 车辆段 + 培训/仿真平台。 | 按网络拓扑图逐节点点数，区分 A/B 网、环网节点与上行端口；光口数另与光模块数量联动核对。 | 清单按每站 1 台计列，而架构为 A/B 双网 → 少算一半；或光口数远大于光模块数量。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R06 | 中心实时 / 历史服务器 | 中心 1 组 + 冗余倍数 + 灾备中心 | 实时服务器、历史服务器通常各主备 2 台；应用级容灾另设灾备中心（按主用中心相当配置、非冗余配置）。 | 按「主用/备用/灾备」三类逐台列出，核对是否含双机切换软件与 License。 | 要求冗余实时服务器自动切换，但清单只有 1 台且无双机软件；灾备中心被漏计。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R07 | 光电转换器 | 传输距离超限的链路数 L | 按链路计，不按站数计；每条链路通常收发成对 → L×2（+备件）。 | 按现场实际距离清单逐条判断（铜缆通常 80~100 m 限制），统计超限链路数。 | PLC 机柜到智慧运行网络机柜距离超 80 m，需按需免费提供光电转换设备，但清单未开项 → 隐性成本。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R08 | 光模块 | 设备光口数 × 成对配置 | 每个光口两端各 1 只；核对速率、波长（单/多模）、传输距离、接口（LC/SC）。 | 统计交换机、防火墙、服务器、光电转换器的光口总数，与本端/对端成对核算。 | 防火墙标配不含光模块，交换机光口无法启用；或按光口数一半配置导致对端缺件。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R09 | 防火墙与信息安全设备 | 安全域边界数、等保分区 | 按网络边界与安全域配置；等保三级还需数据库审计、漏洞扫描、安全运维管理、终端安全管理等能力。 | 按等保控制点逐项对照清单，并确认由本项目供货还是由云平台安全资源池提供。 | 清单仅有大量防火墙，缺数据库审计/漏扫/终端安全；且约定「云平台资源若不能满足需投标人免费提供」→ 等保三级能否通过存疑。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R10 | UPS 容量与蓄电池 | 负载功率合计、后备时间、效率 | 容量 ≈ 负载合计 ÷ 效率 ×(1.2~1.3) 裕量；后备时间按分区要求分别取值。 | 分区（车站/车辆段/周界/中心）分别核算负载与后备时间，再核对电池节数与容量。 | 周界报警要求后备 ≥8 h、其他 ≥1 h、车辆基地 ≥60 min，却统一按 1 h 配置 → 大面积不满足。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R11 | 视频路数与存储容量 | 摄像头路数 C、码流、保存天数 | 容量(TB) = 码流(Mbps)×C×天数×86400÷8÷10⁶×(1+RAID/热备余量)；解码并发另算。 | 按路数、码流、保存天数核算存储；同步核对解码器、工作站与对端交换机的并发能力。 | 典型站视频分析若由我方承担，需新增服务器与存储；每站 4 台工作站接入视频时，对方交换机容量未书面确认。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R12 | 门禁控制器 / 读卡器 / 电子锁 | 门点数 D、每门设备数 | 控制器 = ceil(D / 单控制器门数)；读卡器、电子锁、门磁、出门按钮按每门成套配置。 | 按门点清单逐项统计，核对单控制器门数与事件记录容量。 | 控制器按车站数估算而非按门点数 → 少配；或电子锁「不低于某品牌」却无对应型号检测报告。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R13 | IBP 盘 / 操作台 / 一体化柜 | 车站数 N + 中心，换乘站改造另计 | 通常每站 1 套 IBP 盘与车控室一体化设施，中心大厅另计；换乘站改造按站/屏单独列项。 | 按站逐一列项，核对改造范围（站数、屏数）与定制项（顶柜、色彩方案、电动升降）。 | 「换乘站 IBP 盘改造」是否仅涉及 1 站 2 面屏未明确；顶柜与电动升降功能供货商报价不含。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R14 | 软件 License | 服务器/虚机数 × 每套许可数、并发用户数 | 逐软件核对许可数与授权方式（按物理机/虚机/用户/并发），并核对是否开源或需单独购买。 | 列「软件名称—版本—许可数—授权方式—费用承担」表，与服务器、虚机、用户数比对。 | 每台服务器配套 4×虚机软件 License，是否覆盖全部虚机未核；操作系统/数据库版本未明确，等保整改需另行采购。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R15 | 备品备件与专用工具 | 关键设备数量 / 合同设备总价 3% | 备件常按设备总价一定比例（如 3%）计列，且买方可在总价不变前提下调整种类与数量。 | 核对备件清单种类、数量、单价上限与供货时点；专用工具核对是否齐全及质保期内使用权。 | 备件种类可被调整导致低值高配被调换；「卖方无权在质保期内使用本次采购的专用工具」→ 需另购一套。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
| R16 | 线缆、转换器与辅材 | 链路数 × 长度、接口数量 | 按信号链路逐段核算：设备—接口—线缆—转换器—对端，含规格、长度、数量。 | 画出每条视频/数据/电源链路，逐段核对清单是否开项。 | 带鱼屏只配 1 根线缆却需连接 2 台工作站；1 HDMI + 1 DP 需另配 DP 转换器；缺 2 条 ≥2.5 m HDMI 线缆；触摸 USB 线未列。 | 设备材料表、系统架构图、点数/站数/链路数基线、现场勘查记录 | |
