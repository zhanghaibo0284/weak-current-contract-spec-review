# 解析契约、异常处置与降级规则

> 文件：`rules/parsing.md`
> 职责：定义材料解析的输入契约、异常码与处置动作、降级路径、解析质量声明。
> 地位：`rules/workflow.md` 10.5 的执行细则；与 `rules/inputs.md` 5.4 材料门槛配套。
> 原则：**宁可少判，不可错判**。任何降级都必须在输出中显式声明，禁止把「未读到」写成「不存在」。

---

## 1. 输入格式矩阵

| 格式 | 主能力要求 | 可接受的最低降级 | 禁止行为 |
|---|---|---|---|
| `.docx` / `.doc` | 段落 + 表格 + 样式标题层级 | 仅取正文文本，忽略批注 | 把页眉页脚当作条款正文定性 |
| `.pdf`（有文本层） | 按页抽文本 + 表格 | 按段落流抽取，保留页码 | 用估算页码替代条款号定位 |
| `.pdf`（扫描件） | OCR | OCR 后仅用于检索线索，数值判定须核对原件 | 直接用 OCR 数字下结论 |
| `.xlsx` / `.xls` | 多 sheet + 合并单元格 + 公式计算值 | 读取显示值并标注「含公式」 | 把隐藏行/隐藏 sheet 当作不存在 |
| `.csv` | 分隔符与编码识别（UTF-8 / GBK） | 指定编码重读 | 出现乱码仍继续核算 |
| 图纸（DWG/PDF 图） | 仅读图签与文字说明 | 视为「非文本证据」 | 做尺寸/数量图形量算 |
| 图片（截图） | 仅作 OCR 线索 | 标记「低可信」 | 作为唯一数值来源 |

> 单一文件超过 200 页或超过 30 MB 时，按章节/册拆分处理，并在解析质量声明中记录拆分方式。

---

## 2. 定位锚点规范（f2 字段强制）

统一锚点格式，**章节号优先、页码为辅**：

```text
<文件ID>#<册号>/<章>/<节>/<条款号>[/<表名>#<行号>]
示例：SPEC-01#第1册/3/3.2/3.2.4/设备材料表#第8行
```

1. 文件ID 与 `{{MATERIAL_MANIFEST}}` 中的登记一致。
2. 无条款号时退化为「章 + 段落首句前 12 字」。
3. 页码仅作辅助，必须标「估算」；不得单独使用页码定位。
4. 同一事实在多次复核中锚点保持不变；原文变更时新增锚点并注明版本。

## 3. 异常码与处置

| 异常码 | 触发条件 | 阻断级别 | 必须输出的提示语 |
|---|---|---|---|
| E-01 | 文件无法打开 / 加密 / 损坏 | 阻断该材料 | 「文件《X》无法解析，已标记不可读；依赖该文件的结论均为待核验。」 |
| E-02 | 扫描件无文本层 | 降级（OCR） | 「《X》为扫描件，已 OCR；页码与数值可能存在识别误差，请以原件复核。」 |
| E-03 | 表格含合并单元格 / 公式 / 隐藏行 | 降级 | 「表《X》第 N 列含公式/合并单元格，已按显示值读取，请核对原始口径。」 |
| E-04 | 多册/多版本并存且未声明以何为准 | 阻断该项 | 「存在版本冲突：A 版与 B 版；未确认以何者为准，相关比对结论为待核验。」 |
| E-05 | 图纸/影像等非文本证据 | 降级 | 「图纸仅按文字说明核对，未做尺寸/数量量算。」 |
| E-06 | 关键结论依赖外部知识且无书面证据 | 降级 | 「该项需厂家书面证明或官方支持列表确认，当前仅列核对要点。」 |
| E-07 | 材料齐备度低于门槛 | 阻断全量 | 「必需材料缺 N 项，暂不进行全量逐条判定，详见材料缺口清单。」 |
| E-08 | 编码/乱码导致文本不可用 | 阻断该段 | 「《X》存在编码乱码，已跳过该段并标记待核验。」 |

处置要求：

1. 异常必须**落到具体规则**：在覆盖台账受影响行的 `备注` 写异常码。
2. 同一异常影响多条规则时，逐条标注，不得只写一次。
3. 阻断级异常（E-01/E-04/E-07/E-08）未消除前，报告标题下方须加醒目「结论不完整」标识。

## 4. 表格读取规则

1. **合并单元格**：按合并区域填充值，并在质量声明中列出被填充的列。
2. **公式**：优先读取计算值；无法取值时标「未读取」，不得用 0 代替。
3. **隐藏行列/sheet**：视为存在但标注「隐藏内容未纳入核对」，并提示人工确认。
4. **单位**：识别「套 / 台 / 个 / 米 / 点 / 路」等，单位不一致时先统一再核算，换算过程写入 `判定依据`。
5. **多表关联**：以「设备名称 + 型号 + 安装位置」为键关联设备表与报价册，键不唯一时列出候选，不得强行匹配。

## 5. 解析质量声明（报告必附）

```markdown
### 解析质量声明

| 文件 | 格式 | 读取方式 | 异常码 | 影响范围 | 备注 |
|---|---|---|---|---|---|
| SPEC-01 | PDF（扫描） | OCR | E-02 | PARAM 全部参数项 | 数值以原件为准 |
| BOQ-01 | XLSX | 读取显示值 | E-03 | QTY-R01~R16 | 第 3 列含公式 |

- 已读文件：N / 应交文件：M
- 阻断级异常：无 / 有（列明）
- 结论完整性：完整 / 不完整（原因）
```

> 若未能生成该声明，视为输出不完整；`verify_skill.py` 会对缺少声明的报告模板给出告警。

---

## 6. 禁止行为清单

1. 不得用模型记忆补全缺失条款、型号、数量或标准年号。
2. 不得把估算页码写成「原文第 X 页」。
3. 不得在解析失败时静默跳过，导致覆盖台账缺行。
4. 不得将 OCR 或截图识别结果作为金额、数量、工期的唯一依据。
5. 不得对图纸做图形量算并作为结论证据。
