# 标准规范基线索引

> 文件：`rules/standards-index.md`
> 职责：为 `RISK-G03`（标准现行性）、`RISK-A05`（动态标准）、`RISK-G04`（送检）、`RISK-G05`（进场资料）提供基线清单与核对方法。
> 使用原则：本表只提供**候选标准与核对入口**，不替代官方查新；无 `{{KNOWLEDGE_BACKEND}}` 时必须判「待核验」。

---

## 1. 使用方法

1. 从规格书抽取标准号（正则：`(GB|GB/T|CJJ|CJJ/T|JGJ|DB\d+|ISO|IEC)\s?\d+(\.\d+)?([-—]\d{4})?`）。
2. 与本表比对，命中则取本表名称作参考；未命中则登记为「未见基线，需核验」。
3. 核验三件事：**是否现行**、**是否有强制性条文**、**是否为项目所在地地方标准**。
4. 结论写法：
   - 有官方/书面证据 → 正常定级；
   - 无外部检索能力 → 结论=待核验，`置信度=线索`，进入澄清问题单；
   - 发现规格书引用已废止版本 → 按 `RISK-G03` 定级，至少「中（待核验）」。

> 严禁凭记忆断言某标准「现行有效」或「已废止」。年号仅作检索线索，**须核准**。

## 8. 维护约定

1. 本清单随项目类型增补，**新增条目须注明来源与核对日期**。
2. 每季度复核一次现行性；发现废止项在「备注」标注「已废止，替代标准：X」。
3. 清单变更须更新 `{{RULESET_CHECKSUM}}`，并在评审报告概览注明基线版本。
